# My Dream Dollhouse Shop

A cozy, mobile-first, low-poly 3D game about running a dollhouse shop and building your own dream dollhouse.

- **Platform:** web (mobile browsers) now; iOS / Android store builds later
- **Controls:** simple touch
- **Art:** low-poly 3D, cartoony shading and lighting

Play: https://esalavat.github.io/shop-game/ (add `?debug` for the debug panel)

Run tests: `npm test` · Local server: `npm run serve`, then open http://localhost:8123
